# docs 导航

本目录只保留 3 类内容：

- 当前真相源：`user-manual.md`
- 当前问题清单：`issues-priority.md`
- 审计记录：`audits/`

阅读顺序建议：

1. 先看 `issues-priority.md`，了解当前待处理问题和优先级。
2. 再看 `user-manual.md`，确认当前对外行为和已知限制。
3. 如果要追问题背景，再看 `audits/memory-safety-and-encryption.md`。

归档说明：

- 历史设计稿统一放在 `archive/designs/`
- 已被新清单取代的问题汇总放在 `archive/superseded/`
- 归档文档不再作为主入口，只保留追溯价值
